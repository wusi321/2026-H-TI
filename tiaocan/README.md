# 车载平衡滚球调参台

`tiaocan` 是独立的 React/TypeScript Web 前端，用于记录小车运行时状态、车速、小球运动和舵机状态。它通过浏览器 Web Serial 直接接收 MSPM0G3507 UART2 经 HC-05 蓝牙模块回传的二进制遥测，按任务保存实机运行记录，并用同一份记录进行回放、指标计算、物理模型辨识、候选控制参数仿真和 `BallBalanceConfig` 参数导出。

本目录和根目录 `web/` 是两套互不相干的前端：

- `tiaocan/`：钢珠平衡调参台，关注小球位置/速度、目标位置、车辆速度、舵机角度、前馈和任务阶段；
- `../web/`：小车运动轨迹记录台，关注轮速、偏航角、工作模式和路径积分。

## 目录说明

| 路径 | 内容 |
| --- | --- |
| `src/App.tsx` | 页面主状态机，串口连接、录制、回放、参数应用和 UI 编排。 |
| `src/types.ts` | 遥测、实验记录、调参参数、仿真结果等类型定义。 |
| `src/lib/protocol.ts` | UART2 遥测帧解析/编码，包含新版和兼容旧版帧格式。 |
| `src/lib/serial.ts` | Web Serial 连接和读取封装。 |
| `src/lib/storage.ts` | IndexedDB 实验记录、样本和参数方案存储。 |
| `src/lib/csv.ts` | CSV 导入/导出。 |
| `src/lib/simulation.ts` | 简化物理模型、指标计算、模型辨识和参数转 C。 |
| `src/components/` | 曲线、横梁可视化、指标栏、参数面板、记录库组件。 |
| `tests/` | Playwright UI 冒烟测试。 |

## 运行

```powershell
cd tiaocan
npm install
npm run dev -- --host 127.0.0.1 --port 4317
```

使用桌面版 Chrome 或 Edge 打开：

```text
http://127.0.0.1:4317
```

Web Serial 不支持 Firefox，也不能由网页自动选择 COM 口。

## 串口连接

1. 给 HC-05 和控制板上电，并先在 Windows 中完成蓝牙配对，确认系统生成了串口。
2. 保证没有串口助手或其他程序占用该 COM 口。
3. 在网页中选择任务 3、任务 4/5、任务 6 或任务 7。
4. 单击“选择串口”，在浏览器弹窗中选择 HC-05 对应的传出 COM 口。
5. 串口固定使用 `9600 baud, 8N1, no flow control`。
6. 看到有效帧持续增加且校验错误为 0 后再开始录制。

UART2 在任务有效运行阶段以 20 Hz 发送二进制遥测帧。字段包含小球位置、小球速度、运动方向、目标位置、小车平均轮速/命令速度、加速度、左右轮速度、IMU 偏航角、偏航角速度、舵机角度命令、舵机速度命令、车辆前馈、转弯补偿、任务号、阶段、路线模式和状态标志。完整协议见 `../mspm0g3507_26ti/UART2_TELEMETRY.md`。

任务 3 在视觉识别稳定并开始移动小球后才发送；任务 4/5/6/7 在小车起步速度命令离开 0 后才发送。网页会拒绝与当前任务档不匹配的帧，并在一次录制收到首帧后锁定实际任务号，防止运行中切换任务造成数据混合。

## 分题采集

- 任务 3：从识别静止、0 cm、+5 cm 到 -5 cm 完整录制一次，不要把不同参数的多次实验合在同一记录中。
- 任务 4/5：两题共用行驶平衡参数组。分别保留起步、直线、转弯和停车阶段，重点观察车辆加速度前馈和球的峰值偏差。
- 任务 6：每个指定位置单独记录，至少覆盖 0 cm、正位置和负位置，检查参数在全水管范围内是否一致。
- 任务 7：作为任务 6 的独立控制参数实验档，单独保存记录和参数方案。

录制数据存入浏览器 IndexedDB。建议每次有效实验都导出 CSV；清理浏览器站点数据会删除本地记录。

## 调参流程

1. 先选中一条真实记录，查看实际误差、峰值速度、舵机角度、进入容差时间和目标穿越次数。
2. 使用模型辨识估计舵机延迟、机构增益、阻尼、车辆加速度耦合和偏置，再应用辨识结果。
3. 调整位置环、速度环、制动、舵机响应和前馈参数，对比实测曲线与模拟曲线。
4. 按任务保存参数方案，并导出 `BallBalanceConfig` C 初始化项。
5. 将候选值部署到控制板，重新录制同一工况。只有实机记录改善才算调参有效。

仿真无法完全重现静摩擦、齿隙、管道倾斜、舵机死区、视觉延迟和电池电压变化。它用于筛选参数范围，不能替代实机验证，也不应只根据演示数据生成最终参数。

## 离线采集

无法使用 Web Serial 时，可使用 Python 工具采集 CSV：

```powershell
python -m pip install pyserial
python ..\mspm0g3507_26ti\tools\uart2_telemetry.py --list
python ..\mspm0g3507_26ti\tools\uart2_telemetry.py --port COM7 --csv task3_run.csv
```

停止后将 CSV 导入调参台。`pyserial` 只用于命令行采集，Web 连接串口不需要安装它。
