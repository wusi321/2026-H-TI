# 调参 Web 控制台源码

本目录包含车载平衡滚球系统的 React/TypeScript 调参台源码。调参台通过浏览器 Web Serial 直接读取 MSPM0G3507 UART2 经 HC-05 蓝牙模块回传的二进制遥测，按任务保存实机记录，并用同一份记录完成回放、指标计算、模型辨识、参数仿真和 C 结构体参数导出。

## 当前目录状态

`tiaocan/src` 中有完整业务源码、单元测试和 Playwright UI 测试，但当前目录缺少独立的 `package.json`、`vite.config.ts`、`tsconfig*.json` 和 `package-lock.json`。这些工程配置与依赖锁定文件位于同级 `../web` 目录。

因此：

- 阅读和维护源码以本目录为准；
- 直接在本目录执行 `npm run dev` 需要先补齐/复制工程配置；
- `../web` 更像构建壳和依赖锁定目录，源码主体在本目录。

## 功能概览

- Web Serial 连接 HC-05 蓝牙串口；
- 解析 UART2 20 Hz 二进制遥测帧；
- 按任务 3、4/5、6、7 过滤和锁定实际任务号；
- 实时显示钢珠位置、速度、目标、车速、舵机角度、前馈和转弯补偿；
- 将一次实验记录保存到 IndexedDB；
- 支持 CSV 导入/导出；
- 支持实测曲线回放；
- 对实测数据做简化被控对象辨识；
- 用候选控制参数跑本地仿真；
- 输出可复制到 MCU 的 `BallBalanceConfig` C 初始化片段。

## 遥测来源

UART2 遥测由 `../mspm0g3507_26ti/user/main.c` 的 `duty_100hz()` 定时发送。有效任务阶段以 20 Hz 输出，调参台会拒绝与当前任务档不匹配的帧，避免一次记录混入不同任务。

当前支持任务档：

| 调参台档位 | 接收任务号 | 用途 |
| --- | --- | --- |
| `task3` | 3 | 静止车体下钢珠 `0/+5/-5 cm` 移动。 |
| `task45` | 4 或 5 | 直线/循迹行驶中保持目标位置。 |
| `task6` | 6 | 记忆位置并保持。 |
| `task7` | 7 | 任务 6 的独立参数实验档。 |

协议细节见 `../mspm0g3507_26ti/UART2_TELEMETRY.md`。

## 运行方式

当前目录缺工程配置时，有两种处理方式：

1. 将 `../web` 中的 `package.json`、`package-lock.json`、`vite.config.ts`、`tsconfig*.json`、`index.html` 复制到本目录，再安装依赖运行。
2. 或把本目录 `src` 复制/链接到 `../web/src`，以 `../web` 作为 Vite 工程根目录。

工程配置补齐后运行：

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4317
```

使用桌面版 Chrome 或 Edge 打开：

```text
http://127.0.0.1:4317
```

Web Serial 不支持 Firefox，也不能由网页自动选择 COM 口。

## 串口连接步骤

1. 给 HC-05 和控制板上电，并先在 Windows 中完成蓝牙配对。
2. 确认系统已生成对应 COM 口。
3. 关闭串口助手、Keil 串口窗口或其他占用该 COM 口的程序。
4. 在网页中选择任务档位。
5. 点击“选择串口”，在浏览器弹窗中选择 HC-05 对应 COM 口。
6. 串口固定为 `9600 baud, 8N1, no flow control`。
7. 看到有效帧持续增加、校验错误为 0 后开始录制。

## 调参流程

1. 每次只录制一个明确任务和一组参数，不混合多次实验。
2. 查看实际误差、峰值速度、进入容差时间、目标穿越次数和舵机角度。
3. 用模型辨识估计舵机延迟、机构增益、阻尼、车辆加速度耦合和偏置。
4. 修改位置环、速度环、刹车、舵机响应、车辆前馈等参数。
5. 对比仿真曲线与实测曲线。
6. 导出 C 参数片段，部署到 `mspm0g3507_26ti/apply/ball_balance.c` 对应任务档。
7. 重新实车采集，只有实测改善才认为参数有效。

仿真模型不能完整复现静摩擦、齿隙、管道倾斜、舵机死区、视觉延迟和电池电压变化，只用于缩小候选参数范围。

## 数据存储

实验记录保存在浏览器 IndexedDB，清理浏览器站点数据会删除本地记录。建议每次有效实验都导出 CSV 备份，并按任务、日期和参数版本命名。

## 测试

工程配置补齐后可运行：

```powershell
npm test
npm run build
npm run test:e2e
```

单元测试覆盖协议解析、CSV 和仿真计算；E2E 测试验证调参台页面基础渲染。
