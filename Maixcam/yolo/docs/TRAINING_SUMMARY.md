# 钢珠 YOLO11n-Pose V2 训练结果

## 模型与数据

- 输入尺寸：`320x320`
- 模型：YOLO11n-Pose
- 最优权重：`weights/best.pt`
- ONNX：`weights/best.onnx`
- 最佳 epoch：35
- 训练在 epoch 60 触发早停
- 数据集：`datasets/gangzhu_pose_v2`

数据划分：

| 集合 | 总数 | 正样本 | 负样本 | 增强图 |
| --- | ---: | ---: | ---: | ---: |
| train | 610 | 522 | 88 | 305 |
| val | 68 | 56 | 12 | 0 |
| test | 60 | 60 | 0 | 0 |

测试集全部来自 `datasets/positive_source_voc`，采用连续时间段留出：原视频帧
`900-1199` 和 `3300-3599`。相邻视频帧没有被随机拆到训练集和测试集。
`datasets/negative_samples_185508` 作为空凹槽负样本参与训练和验证。

## 独立测试结果

推荐置信度阈值：`0.40`。

- 总召回率：`96.7%`（58/60）
- 小于 10 px 的远距离钢珠召回率：`84.6%`（11/13）
- 10-20 px 钢珠召回率：`100%`（17/17）
- 大于等于 20 px 钢珠召回率：`100%`（30/30）
- 中心点平均误差：`1.98 px`
- 中心点 P95 误差：`4.73 px`
- 59 张空凹槽图片在 `conf=0.40` 下误检数：`0`

ONNX Runtime 复测为 58/60，中心点平均误差约 `1.97 px`，与 PyTorch
结果一致。ONNX 已通过 `onnx.checker`，固定输入为 `1x3x320x320`，输出为
`1x8x2100`，opset 17。

## 光照与运动退化测试

在 `conf=0.40` 下：

| 场景 | 召回率 |
| --- | ---: |
| 原图 | 96.7% |
| 偏暗 Gamma | 91.7% |
| 偏亮 Gamma | 93.3% |
| 局部阴影 | 93.3% |
| 运动模糊 | 95.0% |
| 偏暗加运动模糊 | 95.0% |
| 三通道灰度 | 88.3% |

上述变换后的负样本均未出现误检。灰度输入可用，但效果低于 RGB，因此部署时
继续向 YOLO 输入 RGB，传统视觉分支可单独使用灰度图。

## MaixCAM 部署

`best.onnx` 仍需通过 MaixHub 转换为 MaixCAM 使用的 `.mud` 和 `.cvimodel`。
转换时保持输入 `320x320`、RGB、batch 1，并使用最终装置场景图片作为 INT8
校准集。主程序建议先使用 `conf=0.40`，再根据真机结果在 `0.35-0.50` 内微调。
